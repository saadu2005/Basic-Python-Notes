# Contributing

Thank you for your interest in improving **Python Fundamentals**.

## How to Contribute

1. Fork the repository.
2. Create a feature branch:

   ```bash
   git checkout -b improve-notes
   ```

3. Add clear notes, examples, or exercises.
4. Use readable Python code and meaningful filenames.
5. Test your examples before submitting them.
6. Commit your changes with a descriptive message.
7. Open a pull request explaining what you improved.

## Content Guidelines

- Keep explanations beginner-friendly.
- Include examples where useful.
- Avoid unnecessary complexity.
- Use consistent Markdown formatting.
- Do not submit code containing passwords, API keys, or private information.
