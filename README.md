# Python Fundamentals 🐍

A structured collection of Python notes, examples, and practice exercises designed to help beginners build a strong programming foundation and support intermediate learners in improving their problem-solving skills.

## 📌 Overview

This repository covers essential Python concepts through concise explanations, practical examples, and hands-on exercises. It is intended to be used as a personal learning reference and a beginner-friendly study guide.

## 📚 Topics Covered

### 🔄 Loops and Control Flow

- `for` loops
- `while` loops
- `break` and loop control
- Practical loop exercises

### ⚙️ Functions

- Function definition and calling
- Parameters and arguments
- Return statements
- Local and global scope
- Lambda functions
- Recursion
- Docstrings
- Function best practices

### 🛠️ Built-in Functions

Examples and practice with commonly used functions, including:

- `print()`
- `input()`
- `len()`
- `range()`
- `sum()`
- `max()`
- `min()`
- `type()`

## 🎯 Practice Exercises

The repository includes exercises such as:

- Printing numbers and even numbers within a range
- Creating countdown programs
- Building a basic password checker
- Calculating averages
- Generating Fibonacci numbers using recursion
- Checking even numbers with lambda functions
- Finding the maximum value using `*args`
- Converting Celsius to Fahrenheit

## ⚠️ Common Mistakes Covered

- Forgetting colons after statements
- Forgetting to use `return`
- Creating infinite recursion
- Using incorrect argument order
- Modifying global variables unnecessarily
- Using mutable default arguments incorrectly

## 🎓 Learning Objectives

By studying this repository, learners can develop the ability to:

- Understand Python syntax and fundamentals
- Use loops and control-flow statements effectively
- Design reusable functions
- Understand scope and recursion
- Practice clean and readable coding techniques
- Solve beginner-level programming problems independently

## 🚀 Recommended Learning Path

1. Study the concept notes.
2. Review the examples.
3. Attempt the exercises without checking the solutions.
4. Compare your approach with the provided solutions.
5. Modify the examples to create your own programs.
